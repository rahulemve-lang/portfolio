# Portfolio - Vulpala Rahul Reddy

Personal portfolio datasheet website for Vulpala Rahul Reddy, first-year Electronics & Communication Engineering (ECE) student at Sreenidhi Institute of Science and Technology (SNIST).

## Features
- **Datasheet Theme**: Minimalist engineering datasheet design aesthetic with custom chip pinout diagram.
- **Responsive**: Fully responsive and mobile-friendly layout.
- **Fast & Lightweight**: Built with clean, vanilla HTML5 and CSS3 (using Google Fonts IBM Plex Mono & IBM Plex Sans).

## Preview
Open `index.html` in any web browser or deploy via GitHub Pages.
